# Mysteria Shop

Создай современный, премиальный и очень эффектный интернет-магазин для компании **DoMagic** — магазина фокусов и игральных карт в Казахстане.

Официальный сайт компании: domagic.kz

### О компании

DoMagic — магазин товаров для фокусников, иллюзионистов, начинающих и профессиональных артистов. Компания работает с 2016 года. Помимо интернет-магазина, DoMagic развивает школу фокусов, проводит встречи фокусников и конкурсы.

Основные категории товаров:

* Игральные карты
* Трюковые карты
* Микромагия
* Сценический инвентарь
* Гиммики
* Аксессуары
* Сувениры
* Костюмы
* Товары для фокусников

В каталоге сотни товаров, поэтому сайт должен выглядеть как настоящий профессиональный интернет-магазин.

### Главная идея дизайна

Сайт должен сразу создавать ощущение **магии, загадочности и премиальности**, но при этом оставаться удобным для покупки.

Стиль:

* тёмная современная тема;
* чёрный/графитовый фон;
* золотистые или фиолетовые акценты;
* красивые свечения;
* лёгкие частицы;
* плавные анимации;
* стеклянные карточки;
* крупные качественные изображения товаров;
* эффект магии, но без перегруженности;
* современный UI уровня премиального магазина.

Не делай сайт похожим на обычный шаблон интернет-магазина. Он должен выглядеть уникально и запоминающеся.
